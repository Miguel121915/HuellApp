Arquitectura de HuellApp

App móvil y web de adopción de mascotas y reunificación de mascotas perdidas · Rama integracion/web-api-oracle

1. Cómo se comunican las partes

  • Clientes → API. La app Flutter y el sitio web no hablan con la base de datos. Todo pasa por la API en PHP, con peticiones HTTPS que devuelven JSON y llevan un token de sesión (JWT).
  • API → Oracle. Solo la API se conecta a Oracle Autonomous Database, en Oracle Cloud, usando el wallet (certificados de conexión segura).
  • Worker de IA. Cuando alguien publica un reporte, la API lanza php artisan ia:procesar en segundo plano. Ese proceso llama a Gemini para analizar y comparar las fotos y luego actualiza las coincidencias. Así el reporte se publica al instante y la persona no espera a la IA.
  • Archivos subidos. Las fotos y documentos se guardan en api/storage/uploads; en la base de datos solo se guarda su ruta.
  • Seguridad. Verificación en dos pasos obligatoria para administradores y refugios, CAPTCHA en el sitio web y límite de intentos de inicio de sesión y de registros.

2. Servicios externos

  • Gemini (Google): lo llama la API para analizar fotos, comparar mascotas y responder en el asistente KIRO. Si un modelo está saturado, usa modelos de respaldo.
  • Cloudflare Turnstile: el navegador muestra el CAPTCHA y la API verifica la respuesta con Cloudflare.
  • Google Sign-In: la app o la web obtienen el token de Google y la API lo valida.
  • OpenStreetMap: lo usan directamente la app y la web para dibujar los mapas; no pasa por la API.
  • Firebase Cloud Messaging: pendiente (HU-19). Servirá para enviar notificaciones push con la app cerrada.

5. Despliegue (HU-25)

Hoy la API y el sitio corren en la computadora de cada integrante. El plan de despliegue (carpeta despliegue/) los instala en una máquina virtual de Oracle Cloud, en la misma nube que la base de datos:

  • nginx recibe las peticiones de internet con HTTPS y reparte entre el sitio, la app compilada y la API.
  • systemd mantiene la API encendida y la reinicia si se cae.
  • Así habrá un link público, funcionará aunque las laptops estén apagadas y todos compartirán la misma carpeta de fotos.

Pendiente: crear la máquina virtual, instalar con despliegue/instalar.sh y configurar HTTPS. Las notificaciones push (HU-19) se completan después, porque necesitan HTTPS.
